# Ortho Motion

A browser tool for making looping orthographic / isometric animations: type cubes, block skylines, interlocking bars, plane stacks, voxel type and growing trees.

Open `index.html` in a browser (needs internet for Three.js and Google Fonts).

## Features
- Six patterns, each with its own settings
- Render styles: wire, hidden line, solid, shaded, ghost
- Text wrapped onto block faces (top / left / right, object or world anchored)
- Spin on X/Y/Z, easing curves, isometric / dimetric / trimetric / front cameras
- Export: web embed (HTML), MP4/WebM loop, GIF, PNG — transparent background optional
